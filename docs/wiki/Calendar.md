# Calendar

Inboxora includes a writable local calendar and read-only calendars. Month, week and work-week views share the same selected date.

## Views and navigation

- Choose Monday or Sunday as the first day of week in the calendar panel.
- The mini-month changes the active date; the main calendar follows it in every view.
- Calendar visibility switches affect only the current user's presentation. They never delete data or disconnect a source.
- On desktop, the calendar panel remains beside the main grid. On mobile, open it on demand from the calendar toolbar.

## Local events and invitations

Only local calendars accept editing. Select an enabled SMTP account explicitly before sending calendar invitations. Imported and contact-date events are read-only.

## Contact dates calendar

**Contact dates** is an automatic, read-only calendar. Birthdays and anniversaries stored on contacts are shown as all-day yearly events. The contact's original year is retained in CardDAV/vCard data, while the calendar shows the date in every matching year.
