# Mobile navigation

- The calendar uses a floating action button for a new event; desktop keeps the toolbar action.
- Mobile Back closes an in-app detail/form before browser history can leave the PWA.
- Select **top** or **bottom** mobile navigation in the calendar panel. The bottom position observes device safe areas; calendar FABs shift above it to remain tappable.
- The calendar panel opens on demand on mobile to preserve screen space.
